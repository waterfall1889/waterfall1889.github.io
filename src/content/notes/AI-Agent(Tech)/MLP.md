# MLP:Multi-Layer Perceptron

---

## 1 **单层感知机（Perceptron）**

- 单层感知机是MLP的基础

- 基本结构：输入→加权求和→激活函数→输出

### 1.1 基本思路

#### 1.1.1 输入

- 输入默认是向量：$x = (x_1,x_2,···,x_n)$

- 向量每一个维度对于最后的影响是不同的，那么我们显然需要给每一个维度都设置专门的权重，让最后的结果正确合理体现不同维度的影响：
  
  $w = (w_1,w_2,···,w_n)$

- 没有偏置时，所有决策边界都必须穿过原点。这会严重限制模型表达能力。权重决定方向，偏置决定位置。因此需要加入偏置量 $b$ 进行修正。

- 偏置量也是偏置阈值，生物神经元不会因为有一点刺激就放电。需要超过某个阈值。

![](../images/AI-Agent(Tech)/MLP/2026-06-16-17-12-07-image.png)

#### 1.1.2 加权求和

- 对于向量根据权重和偏置量进行加权求和计算结果：
  
  $z = \sum_{i=1}^{n} w_ix_i + b$

#### 1.1.3 激活函数

- 判断加权求和的结果是否符合实际的激活神经元/满足需要，这里引入激活函数（Activation Function）

- 最简单的激活函数阶跃函数：
  
  $H(x) = \begin{cases} 0, & x < 0 \\ 1, & x \ge 0 \end{cases}$

- 一个函数 f(x) 能否作为激活函数，并没有绝对严格的数学公理，但在实践中通常希望满足以下几个要求：
  
  - **非线性**：若激活函数是线性的，比如$f(x) = ax + b$，那么两层网络$y = W_2(W_1x + b_1)+b_2$ 这展开后依旧是线性的关系，这样的多层感知机仅有可能在线性意义上提高了网络的表达能力，并没有使模型拥有更广的拟合能力。故一般必须是非线性的，比如$sigmoid(x) = 1/(1+e^{-x})$、$ReLU(x) = max(0,x)$
  
  - **几乎处处可导（almost everywhere differentiable）**：神经网络训练依赖反向传播：$∂Loss / ∂w$;因此，需要$f'(x)$易于计算。sigmoid处处可导，而ReLU在0处不可导，因此后者0处导数一般直接强行定义为0或者1
  
  - **梯度不能太容易消失**:这是深层网络的重要问题;sigmoid当x趋于正负无穷的情况下导数趋于0，多层相乘后梯度接近消失，因此深层网络更多采用ReLU
  
  - **计算简单**：训练时要计算数十亿次激活。低计算量意味成本下降。
  
  - **输出分布稳定（最好零中心）**:比如$tanh$常用于RNN
  
  - **不容易梯度爆炸**：$|f'(x)|$不能过大，否则梯度可能爆炸，训练极不稳定。

#### 1.1.4 常用激活函数

| **激活函数名称**             | **数学表达式**                                                                         | **输出范围**                   | **核心特点**                                                         | **典型使用场景**                                                    |
| ---------------------- | --------------------------------------------------------------------------------- | -------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------- |
| **Step**<br>(阶跃函数)     | $f(x)=\begin{cases}1,&x\ge0 \cr 0,&x<0\end{cases}$                                | $\{0, 1\}$                 | 不可导（在 $x=0$ 处），其余地方导数均为 0；**无法用于反向传播**梯度下降。                      | 早期感知机模型、理论演示；**现代深度学习中已基本弃用**。                                |
| **Sigmoid**            | $f(x)=\frac{1}{1+e^{-x}}$                                                         | $(0, 1)$                   | 曲线平滑；**输出非零中心**；极值区存在严重的**梯度消失**问题；含幂运算，计算量大。                    | 二分类任务的**输出层**。早期曾用于隐藏层，现已被替代。                                 |
| **Tanh**<br>(双曲正切)     | $f(x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}$                                              | $(-1, 1)$                  | **零中心对称**（Zero-centered），收敛速度快于 Sigmoid；但在极值区仍存在**梯度消失**问题。      | 循环神经网络（**RNN / LSTM**）的隐藏层。                                   |
| **ReLU**<br>(修正线性单元)   | $f(x)=\max(0,x)$                                                                  | $[0, +\infty)$             | **计算极快**（只需阈值判断）；正区间解决梯度消失；具有稀疏激活特性；存在 **Dying ReLU（神经元坏死）** 问题。 | 传统深度神经网络（如 **CNN**、多层感知机 MLP）**隐藏层的默认首选**。                    |
| **Leaky ReLU**         | $f(x)=\begin{cases}x,&x\ge0 \cr \alpha x,&x<0\end{cases}$<br>*(通常 $\alpha=0.01$)* | $(-\infty, +\infty)$       | 给负区间一个微小的斜率，**彻底解决了 Dying ReLU 问题**；保留了 ReLU 计算速度快的优点。           | 当普通 ReLU 导致网络中大量神经元“死掉”时使用；常用于 **GAN（生成对抗网络）**。               |
| **GELU**<br>(高斯误差线性单元) | $f(x)=x\Phi(x)$<br>*($\Phi(x)$为正态分布累积分布函数)*                                       | $\approx [-0.17, +\infty)$ | 全局平滑、非单调；在 $x=0$ 附近平滑过渡；结合了**随机正则化（Dropout）与激活函数**的双重思想。         | 现代 NLP / CV 大模型（如 **BERT、GPT 系列、Transformer、ViT**）的标配隐藏层激活函数。 |
| **SiLU**<br>(Swish)    | $f(x)=\frac{x}{1+e^{-x}}$                                                         | $\approx [-0.28, +\infty)$ | **无上界、有下界、平滑、非单调**；具备自门控（Self-Gated）特性；深层网络中的表现通常优于 ReLU。        | 现代高效计算机视觉模型（如 **YOLOv5 / v7 / v8、EfficientNet**）的隐藏层。         |

## 2 多层感知器

MLP 是**层级化、全连接**的神经网络结构，层与层之间无跳过、无循环，神经元之间**全连接**（相邻层的任意两个神经元都有连接），整体分为3类核心层

![](../images/AI-Agent(Tech)/MLP/2026-08-06-17-22-42-image.png)

三层结构：Input layer输入层，Hidden layer隐藏层（一般多层），Output layer输出层

**普适逼近原理**（Universal Approximation Theorem）：一个具有至少一层的隐含层的前馈神经网络，并且隐含层包含有限数量的神经元（即多层感知机），它可以以任意精度逼近任意一个定义在 $ℝ^𝒏$ 上的连续函数，这为神经网络的有效性给出了最基础的理论保障

![](../images/AI-Agent(Tech)/MLP/2026-06-16-17-16-13-image.png)

### 2.1 输入层

- 接受原始数据和特征，神经元数量等于特征维度（比如28×28的图片对应784维度）

- 不做任何计算和处理

### 2.2 隐藏层

- MLP的核心层，可以设置一层或者多层（多层对应深度多层感知机），**层数/神经元数是关键超参数**。

- 完成**特征提取与非线性变换**：对**输入层的特征加权求和**后，通过**激活函数**输出，实现特征的升维/抽象。

- **相邻隐藏层之间为全连接关系**。

### 2.3 输出层

- 输出模型的**最终预测结果**，神经元数量由**任务类型**决定：
  
  - 二分类任务：1个神经元（输出0/1）；
  
  - 多分类任务：神经元数 = 类别数（如MNIST手写数字分类，设10个神经元）；
  
  - 回归任务：1个神经元（输出连续值）。

- 激活函数按需选择（分类用**Softmax/Sigmoid**，回归用Identity等等）。

### 2.4 工作原理

- 数据通过Input Layer传入Hidden Layer，对于Hidden Layer每个神经元，通过某些方法初始化其权重向量 $W$ 和偏移量 $b$

- 初始化完成后，利用这些神经元去做前向传播，直到算出来“预测值”或者结果

- 根据结果去计算Loss，比如交叉熵用于计算分类问题的loss

- 反向传播，用链式法则计算 **Loss 对每个参数的梯度**，然后对应移动一定距离（学习率）进行调整，直到结束

举例说明：现在有一个2层Hidden Layer的MLP，Input Layer 2个神经元，Hidden Layer第一层3个神经元，第二层2个神经元，Output Layer 1个神经元，用于做二分类任务。

![](../images/AI-Agent(Tech)/MLP/2026-06-16-17-55-24-image.png)

#### 2.4.1 初始化

- 初始化一般需要随机，但是仍然有方法，不可以全部取0，初始化的作用是：**打破对称性 + 保持信号稳定传播**

- Xavier初始化：（Sigmoid / Tanh 常用）：
  
  $W ～ U(-\frac{\sqrt6}{\sqrt{n_{in} + n_{{out}}}}, \frac{\sqrt6}{\sqrt{n_{in} + n_{{out}}}})$ 或者 $W ～ N(0,\frac{1}{n_{in}})$

- He初始化：
  
  $W ～ N(0,\frac{2}{n_{in}})$

- b通常取0或者很小的数

- $n_{in}$代表此神经节点的入度，$n_{out}$代表此神经节点的出度；注意，神经元之间通过“层级连接矩阵”连接，每个**连接**对应一个权重

#### 2.4.2 前向传播（预测）

- 利用初始化后的偏移量、权重，每层计算、用激活函数转化，然后依次传到下一层

- 传到下一层后，继续传播到输出层

- 对于第 $l$ 层：
  
  - 线性变换：$z^{(l)}=W^{(l)}a^{(l−1)}+b^{(l)}$
  
  - 非线性激活：$a^{(l)}=f(z^{(l)})$
  
  其中：
  
  - $a^{(0)}=x$（输入层）
  - $W^{(l)}$：第 $l$ 层权重
  - $b^{(l)}$：该层的偏置
  - $f(⋅)$：激活函数（ReLU / Sigmoid / Tanh）

![](../images/AI-Agent(Tech)/MLP/2026-06-16-18-17-07-image.png)

#### 2.4.3 反向传播（训练）

- 计算损失函数对每个参数（W, b）的梯度，并据此更新参数，使损失下降。

![](../images/AI-Agent(Tech)/MLP/2026-06-16-18-28-13-image.png)

- 每一层的梯度 = 下一层传回来的误差 × 本层激活函数导数 × 本层输入

- 调整参数：$W ← W - η\frac{∂L}{∂W}$ , $b ← b - η\frac{∂L}{∂b}$ ，其中 $η$ 为学习率，学习率不能过小或者过大

### 2.5 MLP的缺陷

1. **全连接导致参数爆炸**：随着特征维度/隐藏层神经元数增加，权重矩阵的参数会**呈指数级增长，易过拟合**；
2. **缺乏特征的空间/时序归纳偏置**：无法提取图像的**空间特征**（如纹理、形状）、文本的**时序特征**（如语序），对图像、序列数据的效果远差于CNN/RNN；
3. **过拟合风险高**：对小数据集易过拟合，需结合正则化（L1/L2、Dropout）、早停等策略；
4. **对特征缩放敏感**：输入特征的量纲差异会影响训练效果，需提前做归一化/标准化。

## 2.6 正则化策略

正则化的核心目标是：

> **在拟合训练数据的同时，限制模型复杂度，从而提升泛化能力（generalization）**

神经网络的**泛化能力**（Generalization Ability）是指训练好的模型对**未见过的新数据**（测试集或实际应用场景）进行准确预测的能力。

### 2.6.1 为何常规的MLP容易参数爆炸和过拟合？

- 层数增加 → 参数线性增长

- **宽度增加 → 参数平方级增长（非常快）**

- 堆叠多层后极易达到千万级

- MLP 是**通用函数逼近器（Universal Approximation Theorem）**：
  
  - 理论上可以拟合任意复杂函数
  - 但也意味着可以“记住噪声”
  
  因此：
  
  - 训练误差 ↓
  - 测试误差 ↑

- 在深层 MLP 中：
  
  - 激活函数（如 ReLU）在某些区域可能持续激活
  - 权重更新可能导致：
    - 参数不断放大（exploding weights）
    - 或进入“死区”

- 相比 CNN / Transformer：
  
  - MLP 没有局部性、共享权重等约束
  - → 自由度过高 → 更容易过拟合

### 2.6.2 Dropout策略

2012年，Hinton 团队提出 **Dropout**，通过随机“关闭”神经元来增强模型鲁棒性。

Dropout 的核心思想是：在训练时，随机丢弃一部分神经元的输出，迫使网络不依赖任何单个神经元，从而提高泛化能力。

- 训练阶段：每个神经元以概率 p 被保留，以 1-p 被置零（p 通常取 0.5）。

- 测试阶段：所有神经元均参与计算，但输出需乘以 p。

- 类似于多人投票决策（集成学习），避免个别“专家”主导结果。

实现：

设某层神经元的输出为 `x = [x₁, x₂, ..., xₙ]`，Dropout 的实现步骤：

1. 生成随机掩码（Mask）`m = [m₁, m₂, ..., mₙ]`，其中 `mᵢ ~ Bernoulli(p)`。

2. 被保留的神经元的输出变为 `xᵢ * mᵢ / (1-p)`（缩放补偿）
- **优点**：
  
  - **防止过拟合**：减少神经元共适应（Co-adaptation）。  
  
  - **相当于隐式模型集成**：每次前向传播相当于训练一个子网络。  
  
  - **计算高效**：仅需在训练时增加随机掩码生成。

- **缺点**：
  
  - **训练时间更长**：需要更多迭代才能收敛。  
  
  - **可能丢失重要信息**：若 `p` 设置不合理，会破坏关键特征。  
  
  - **不适用于所有层**：如 BatchNorm 层后加 Dropout 可能导致不稳定

### 2.6.3 L1/L2 正则化

**L1 正则化**与**L2 正则化**是防止模型过拟合的两种核心方法。它们通过在损失函数中加入**惩罚项**限制模型参数的复杂度，从而提升泛化能力。

- 如果只是用均方差等作为损失函数，虽然训练误差可能极低，但模型会：
  
  - 对噪声极其敏感
  - 泛化能力差
  - 出现过拟合
  
  故加入约束：$L = L_{data} + λR(W)$

**L2 正则化**（Weight Decay 权重衰减）：加入L2范数

$$
||W||^2_2= \sum^{}_{i}w_i^2

$$

$$
L = L_{data}+ λ\sum^{}_{i}w_i^2
$$

**推导**：

对于单个权重：

$$
L = L_{data} + λw^2
$$

求导：

$$
\frac{∂L}{∂w} = \frac{∂L_{data}}{∂w} + 2λw
$$

梯度下降：

$$
w = w - η(\frac{∂L_{data}}{∂w} + 2λw)
$$

整理：

$$
w = (1 - 2ηλ)w - η\frac{∂L_{data}}{∂w}
$$

由于每次更新的的系数$(1-2λη)$必然小于1，故$|w|$会越来越小。

从几何意义上讲，这是圆形约束：

优化目标：

- 损失函数等高线
- 与圆第一次相切的位置

作为最终解。

**L2的特点**：权重整体缩小衰减，不容易变成0，不会剧烈震荡，泛化能力强，训练稳定（梯度连续），是主流的思路（MLP/CNN/Transformer）;不过不能自动做特征选择，参数不可能到0，模型比较复杂

**L1正则化（Lasso）**：加入L1范数

L1 范数：

$$
||W||_1 = \sum_i |w_i|
$$

损失函数：

$$
L = L_{data} + λ \sum_i |w_i|
$$

对于单个参数：

$$
L = L_{data} + λ|w|
$$

求导：

$$
\frac{∂|w|}{∂w} = sign(w)
$$

即：

当 w > 0 时，sign(w) = 1；当 w < 0 时，sign(w) = -1

因此：

$$
\frac{∂L}{∂w} = \frac{∂L_{data}}{∂w} + λ \cdot sign(w)
$$

参数更新：

若 w > 0：

$$
w = w - ηλ
$$

若 w < 0：

$$
w = w + ηλ
$$

结果：所有权重都会被"强行往0拉"。

例如：

0.05 → 0.03 → 0.01 → 0

最终大量参数变成：0

**L1**在实质上是菱形约束，优化过程中最优点非常容易落在坐标轴上。因此容易产生稀疏解。其梯度大小变化幅度很小，可以进行自动特征选择，可解释性强，模型得到压缩，但是训练不稳定。

| 对比项      | L1 正则化 (Lasso)                   | L2 正则化 (Weight Decay/Ridge)    |
| -------- | -------------------------------- | ------------------------------ |
| 正则项      | $λ\sum_i \|w_i\|$                | $λ\sum_i w_i^2$                |
| 损失函数     | $L = L_{data} + λ\sum_i \|w_i\|$ | $L = L_{data} + λ\sum_i w_i^2$ |
| 梯度       | $λ \cdot sign(w)$                | $2λw$                          |
| 对大权重惩罚   | 较强                               | 很强                             |
| 对小权重惩罚   | 仍保持恒定                            | 非常弱                            |
| 参数是否变0   | 容易                               | 几乎不会                           |
| 稀疏性      | 强                                | 弱                              |
| 特征选择能力   | 强                                | 无                              |
| 可解释性     | 高                                | 一般                             |
| 训练稳定性    | 较差                               | 很好                             |
| 对相关特征处理  | 倾向保留一个                           | 倾向共同保留                         |
| 泛化能力     | 较好                               | 很好                             |
| 深度学习使用频率 | 较少                               | 非常高                            |
| 典型算法     | Lasso Regression                 | Ridge Regression               |
| 适用场景     | 特征选择、压缩、可解释模型                    | MLP、CNN、Transformer、LLM        |
| 主要缺点     | 不稳定、可能误删特征                       | 无法产生稀疏解                        |

### 2.6.4 BatchNorm批量归一化

2015年，Ioffe 与 Szegedy 提出 **Batch Normalization（BN，批量归一化）**，通过对每一 mini-batch 的激活值做标准化，缓解深层网络训练不稳定的问题。

**核心思想**：深层网络训练时，前面层的参数更新会改变后面层的输入分布（内部协变量偏移，Internal Covariate Shift），导致梯度传播困难、收敛缓慢。BatchNorm 在每一层对 batch 内数据做归一化，使每层输入保持相对稳定，从而加速训练并带来一定的正则化效果。

**典型插入位置**：线性变换（全连接 / 卷积）之后、激活函数之前，顺序为：线性层 → BatchNorm → 激活函数。

设某层在一个 mini-batch 上的输出为 $x = [x_1, x_2, ..., x_m]$（$m$ 为 batch size），BatchNorm 的计算步骤：

**1. 计算 batch 均值与方差**

$$
μ_B = \frac{1}{m}\sum_{i=1}^{m} x_i
$$

$$
σ_B^2 = \frac{1}{m}\sum_{i=1}^{m}(x_i - μ_B)^2
$$

**2. 标准化**

$$
\hat{x}_i = \frac{x_i - μ_B}{\sqrt{σ_B^2 + ε}}
$$

其中 $ε$ 是一个极小常数（如 $10^{-5}$），防止分母为 0。

**3. 缩放与平移（可学习参数）**

$$
y_i = γ\hat{x}_i + β
$$

$γ$（scale）和 $β$（shift）由网络自己学习。若 $γ = \sqrt{σ_B^2 + ε}$、$β = μ_B$，则 $y_i ≈ x_i$，BatchNorm 可退化为近似恒等变换，不会强行破坏原有表示。

**训练 vs 推理**：

- **训练阶段**：用当前 mini-batch 的 $μ_B$、$σ_B^2$ 做归一化；同时用指数移动平均（EMA）累积全局均值 $μ_{running}$ 和方差 $σ_{running}^2$。
- **推理阶段**：不再依赖 batch 统计（batch size 可能为 1），改用训练时累积的 $μ_{running}$、$σ_{running}^2$，保证输出确定、可复现。

**与 MLP 的关系**：

- 2.5 节提到 MLP **对输入特征缩放敏感**，通常需对原始特征做标准化；BatchNorm 则在**网络内部各层**持续做归一化，减轻深层 MLP 中激活值分布漂移的问题。

- 与 Dropout 类似，BatchNorm 对 batch 统计的随机性也带来**轻微正则化**；但二者不宜随意叠放——Dropout 会改变激活值分布，放在 BatchNorm 之后可能导致统计不稳定（见 2.6.2 节）。

- **优点**：
  
  - **加速收敛**：允许使用更大学习率，训练更快。
  - **稳定梯度**：缓解梯度消失 / 爆炸，深层 MLP 更易训练。
  - **减轻对初始化的依赖**：对权重初值不那么敏感。
  - **轻微正则化**：mini-batch 统计的噪声有助于泛化。
  - **广泛适用**：MLP、CNN 等架构中均可使用（Transformer 中常用 LayerNorm 替代，原理类似但归一化维度不同）。

- **缺点**：
  
  - **依赖 batch size**：batch 过小时，$μ_B$、$σ_B$ 估计噪声大，效果变差。
  - **推理与训练行为不一致**：需额外维护 running mean / variance。
  - **对小 batch / 在线学习不友好**：batch size = 1 时效果差，需改用 GroupNorm、LayerNorm 等变体。
  - **与 Dropout 搭配需谨慎**：一般建议 BatchNorm 在前、Dropout 在后，或二者只选其一。

**小结**：BatchNorm 不直接惩罚权重（不像 L1/L2），而是通过**稳定各层激活分布**间接提升泛化能力，是现代深度学习（含 MLP）中最常用的训练技巧之一。

### 2.6.5 早停策略

**早停机制（Early Stopping）** 是一种在机器学习模型训练过程中常用的正则化技术，尤其在迭代训练算法（如神经网络、梯度提升树等）中广泛使用。其核心思想是：**在模型开始过拟合之前停止训练**，从而提高模型在新数据上的泛化能力。

**为什么需要早停？**

在迭代训练过程中，训练损失 $L_{train}$ 通常会随 epoch 增加而持续下降；但验证损失 $L_{val}$（或测试损失）往往呈现**先降后升**的趋势：

- **训练初期**：模型对训练集和验证集都在有效学习，$L_{train}$ 和 $L_{val}$ 同步下降。
- **训练中期**：模型继续拟合训练数据，$L_{val}$ 达到最低点——此时模型在新数据上表现最好。
- **训练后期（过拟合）**：模型开始过度学习训练数据中的噪声和特有模式；$L_{train}$ 可能继续下降，但 $L_{val}$ 开始上升，泛化能力变差。

早停的目标就是找到 $L_{val}$ 的最低点，在此停止训练，避免进入过拟合阶段。

**工作原理**

**1. 划分数据集**

将原始数据划分为：

- **训练集（Training Set）**：用于参数更新
- **验证集（Validation Set）**：用于监控泛化能力，不参与梯度更新

**2. 监控指标**

在验证集上选取一个指标持续监控，最常用的是验证损失（Validation Loss），也可以是验证准确率（Validation Accuracy）等。

**3. 设置 Patience（耐心值）**

Patience 是关键超参数：定义验证指标**连续多少个 epoch 没有改善**后，才触发停止。

**4. 训练流程**

1. 在训练集上完成一个 epoch 的训练。
2. 在验证集上评估当前模型性能。
3. 若验证指标优于历史最优（如 $L_{val}$ 更低），则**保存当前模型权重**，并将 patience 计数器**重置为 0**。
4. 若验证指标未改善，则 patience 计数器 **+1**。
5. 当 patience 计数器达到预设值时，**停止训练**。
6. 最终部署的模型为验证集上表现最优的**已保存 checkpoint**，而非最后一轮的权重。

用伪代码概括：

```
best_val = ∞
patience_counter = 0

for epoch in range(max_epochs):
    train_one_epoch()
    val_loss = evaluate_on_validation_set()

    if val_loss < best_val:
        best_val = val_loss
        save_model()
        patience_counter = 0
    else:
        patience_counter += 1
        if patience_counter >= patience:
            break
```

- **优点**：
  
  - **防止过拟合**：在泛化能力最佳时停止，避免在训练集上过度学习。
  - **节省训练时间**：无需训练至完全收敛，验证性能不再提升即可提前终止。
  - **简化超参数调优**：与 L1/L2 不同，无需调节正则化强度 $λ$，主要只需调节 patience。

- **缺点与注意事项**：
  
  - **需要独立验证集**：会占用一部分数据，减少可用于训练的有效样本量。
  - **Patience 需调优**：过小 → 过早停止，可能欠拟合；过大 → 仍可能进入过拟合。
  - **验证集需有代表性**：若验证集不能代表真实数据分布，早停决策可能失效。
  - **验证曲线未必单调**：$L_{val}$ 可能短暂上升后再下降，patience 过小会错过后续更优解。

**小结**：早停是一种简单有效的正则化策略——通过监控验证集性能决定何时停止训练，在拟合训练数据与泛化到未见数据之间取得平衡。对 MLP 等迭代训练的神经网络而言，常与 Dropout、L2 等方法配合使用。

### 2.6.6 Bagging策略

Bagging算法 （英语：Bootstrap aggregating，引导聚集算法），又称装袋算法，是机器学习领域的一种团体学习算法。最初由Leo Breiman于1996年提出。Bagging算法可与其他分类、回归算法结合，提高其准确率、稳定性的同时，通过降低结果的方差，避免过拟合的发生。

**大致思路**：

- 对于给定的训练样本S,每轮从训练样本S中采用有放回抽样(Booststraping)的方式抽取M个训练样本,共进行n轮，得到了n个样本集合，需要注意的是这里的n个训练集之间是相互独立的。

- 在获取了样本集合之后，每次使用一个样本集合得到一个预测模型，对于n个样本集合来说，我们总共可以得到n个预测模型。

- 如果我们需要解决的是分类问题，那么我们可以对前面得到的n个模型采用投票的方式得到分类的结果，对于回归问题来说，我们可以采用计算模型均值的方法来作为最终预测的结果。

**关于随机采样**:

**随机采样（bootstrap sample）从n个数据点中有放回**地**重复随机抽取**一个样本（即同一个样本可被多次抽取），共抽取n次。创建一个与原数据大小相同得数据集，但有些数据点会缺失（大约1/3），有些会重复。  
举例说明：  
原数据集：[‘a’, ‘b’, ‘c’, ‘d’]  
随机采样1：[‘c’, ‘d’, ‘c’, ‘a’]  
随机采样2：[‘d’, ‘d’, ‘a’, ‘b’]  
…  
对于缺失得数据点我们常常称之为袋外数据(Out Of Bag, 简称OOB)。这些数据没有参与训练集模型的拟合，因此可以用来检测模型的泛化能力。
